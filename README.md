# BraveBrand Figma plugin for Buzz

Open a Figma file beside your Buzz conversation on macOS. The viewer is free and works independently of Fred or a BraveBrand Premium membership.

## Install in Buzz Beta

1. Open Settings → Plugins → Manage plugins → Add.
2. Choose the Git or GitHub repository option. Paste https://github.com/lukesbrave/bravebrand-figma-plugin and leave Branch or tag blank.
3. Click Find. Select Figma in the dist folder, review the plugin, install it and switch it on.
4. Open a conversation and click Open Figma in the conversation header. Sign in to your own Figma account if prompted. Open a file you have access to and check that it appears beside the chat.

The Figma panel displays the file. An agent editing its layers also needs its own authenticated Figma MCP connection and edit access to that file.

To update later, open the plugin’s details and choose Check for updates → Update.
